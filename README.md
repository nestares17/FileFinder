# FileFinder
Un buscador de archivos ultra rapido. 

- Busca 80.000 archivos por segundo.

- Búsqueda por nombre. Encuentra coincidencias parciales sin distinguir mayúsculas. Si escribes una ruta (con \, / o :), busca en la ruta completa.

- Historial de búsquedas guardado en %APPDATA%\FileFinder.

- Acciones: abrir archivo, abrir carpeta contenedora y copiar ruta (con doble clic o clic derecho).

- Ignora carpetas pesadas e inútiles: Papelera, System Volume Information, WinSxS, node_modules y .git.

- Verion en Ingles y Español.


# Como Installar 

- Dirijase a la carpeta installer.
- Descargue el archivo "FileFinder-Setup".

# Aviso!

- Durante la instalacion pueden aparecer mensajes de seguridad por el hecho de que no es una aplicacion oficial.
  El proyecto es open source por lo que no contiene nada maligno.
